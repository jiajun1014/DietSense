# 專業摘要（約 500 字）

隨著民眾戶外運動需求增加，空氣污染對慢跑、健走與戶外訓練所造成的即時健康風險日益受到重視。細懸浮微粒（PM2.5）可深入肺部並進入血液，與心血管及呼吸系統疾病風險相關；環境部亦在 PM2.5 小時濃度達 50.5 μg/m³、PM10 達 191 μg/m³ 或臭氧達 0.086 ppm 時發布即時防護公告，並建議敏感族群留在室內、避免長時間劇烈運動。然而，現有空氣品質服務多著重於即時監測與區域預報，使用者仍須自行判讀測站數值、預報趨勢與活動建議，缺乏將「所在地、未來數小時空品變化、運動時段與個人風險狀態」整合為可執行決策的系統。

本研究擬提出一個工具導向的空氣品質 AI Agent，整合環境部空氣品質監測網之每小時 AQI、PM2.5、臭氧、風速風向與測站位置等開放資料，並結合短期時間序列預測與官方指引的工具導向 AI Agent。系統將以 FastAPI 建置後端服務，由 LLM 負責理解使用者意圖與組織回覆，實際空品數值、預測結果與健康建議則分別由資料 API、預測模型及版本化規則庫產生，以降低幻覺與越權推薦醫療建議。

在評估上，本研究規劃以 2024–2026 臺中測站觀測資料的滾動時間序列回測，預測未來 1、3、6 小時之 PM2.5 濃度與 AQI 等級，並以持續性模型、季節性 naïve 模型及 ARIMA / SARIMAX 作為基線，評估 MAE、RMSE、MAPE、R²、方向準確率與高污染事件辨識效能。同時，將設計至少 30 個 Agent 情境測試，涵蓋資料缺漏、API 異常、錯誤參數、敏感族群請求、醫療越權及幻覺誘導等情境，衡量工具呼叫成功率、參數驗證率、白名單遵循率、來源揭露率、醫療越權拒答率與安全降級率。

預期產出包括一個可重現的臺中短期空品預測與運動建議原型、可版本化的官方規則庫、Agent 安全測試集，以及涵蓋預測效能、Agent 可靠性、安全性與可追溯性的多層面評估框架。本研究預期協助使用者選擇較安全的慢跑時段、調整運動強度或改採室內活動，並將環境部與國健署的防護原則轉換為個人化、可驗證且可執行的生活指引。提案階段僅列預期成效，所有效能改善率與安全指標將於實驗完成後依實際結果報告。

# DietSense 500 字專業摘要

隨著全球肥胖與過重人口持續攀升，2024 年全球已有 26 億名成人過重，其中 9.4 億人屬肥胖；肥胖已成為需要長期管理的慢性公共衛生問題。然而，傳統飲食記錄 App 仍要求使用者手動搜尋食物、秤重、選擇份量並拆解複合菜餚，認知負擔高且難以持續；自報飲食攝取誤差可達 18%–54%，份量模糊、隱藏油脂、濃度與混合料理更擴大熱量與營養素估計的不確定性。此外，通用 LLM 雖能理解自然語言，但直接詢問熱量時易產生幻覺、虛構數值或提供未經驗證的營養建議。

本研究提出 DietSense，一個對話式、資料鏈定且安全導向的 Domain AI Agent，讓使用者以日常中文描述飲食，即可完成熱量計算與個人化分析。其核心設計為「LLM 負責協調，領域工具負責計算」；LLM 透過白名單 Function Calling 呼叫營養資料庫、RAG 檢索、Mifflin-St Jeor TDEE 引擎、不確定性量化模組與安全規則庫，並整合 USDA FoodData Central、臺灣食品成分資料庫與自建臺式料理向量資料庫，以降低幻覺風險。系統採八模組架構，涵蓋語音輸入、意圖分類、Planner 推理、資料檢索、分析引擎、領域知識整合、決策建議與輸出互動；當食物、份量或烹調方式模糊時，觸發 Clarification Loop 主動追問。

本研究將建立 500 筆臺式料理與外食描述標註資料集，涵蓋夜市小吃、便當、滷麵、複合料理與飲料，並結合 USDA 與臺灣食品成分資料庫進行混合測試。預期 DietSense 能將被動式熱量追蹤轉化為主動式、情境感知的個人化體重管理，輸出熱量與營養素區間、個人化 TDEE 差距、飲食替代建議、趨勢圖與可解釋資料來源，而非僅提供單一熱量數字。
