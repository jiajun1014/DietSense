# DietSense 精簡摘要（約 300 字）

全球肥胖與過重人口持續攀升，2024 年全球已有 26 億名成人過重，其中 9.4 億人屬肥胖，肥胖已成為需長期管理的慢性公共衛生問題。然而，傳統飲食記錄 App 仍要求使用者手動搜尋食物、秤重、選擇份量並拆解複合菜餚，認知負擔高且難以持續；自報飲食攝取誤差可達 18%–54%，份量模糊、隱藏油脂、湯底與混合料理更擴大熱量與營養素估計的不確定性。此外，通用 LLM 雖能理解自然語言，但直接詢問熱量時易產生幻覺、虛構數值或提供未經驗證的營養建議。本研究提出 **DietSense**，一個對話式、資料錨定且安全導向的 Domain AI Agent，讓使用者以日常中文描述飲食，即可完成熱量計算與個人化分析。其核心設計為「LLM 負責協調，領域工具負責計算」：LLM 透過白名單 Function Calling 呼叫營養資料庫、RAG 檢索、Mifflin-St Jeor TDEE 引擎、不確定性量化模組與安全規則庫，並整合 USDA FoodData Central、臺灣食品成分資料庫與自建臺式料理向量資料庫，以降低幻覺風險。系統採八模組架構，涵蓋語音輸入、意圖分類、Planner 推理、資料檢索、分析引擎、領域知識整合、決策建議與輸出互動；當食物、份量或烹調方式模糊時，觸發 Clarification Loop 主動追問。本研究將建立 500 筆臺式料理與外食標註資料集，涵蓋夜市小吃、便當、湯麵、複合料理與飲料，並結合 USDA 與臺灣食品成分資料庫進行混合測試。預期 DietSense 能將被動式熱量追蹤轉化為主動式、情境感知的個人化體重管理，輸出熱量與營養素區間、個人化 TDEE 差距、飲食替代建議、趨勢圖與可解釋資料來源，而非僅提供單一熱量數字。
